# UFC Fight Analytics

Predict UFC fight outcomes using historical fighter stats and machine learning —
with a Streamlit UI and an automated review-and-retrain loop that tracks how the
model performs against real events.

## Results

Test metrics on the rolling 18-month holdout (fights the model never saw,
evaluated after each retrain — see `just model-info` for the live numbers):

| Model | Accuracy | AUC |
|---|---|---|
| **Logistic Regression** | **70.8%** | **0.781** |
| Random Forest | 69.6% | 0.774 |
| Gradient Boosting | 67.9% | 0.748 |

The best candidate by AUC is saved automatically; the winner can change between
retrains. Real-world accuracy against upcoming events is tracked separately in
`data/predictions.csv` (see the Review & Retrain page).

### Known limitations

- Career-average stats (SLpM, takedown accuracy, …) come from the fighter's
  profile *as of scrape time*, not as of each historical fight — they can't be
  reconstructed from this source. Historical `hist_*` features and age (when
  date of birth is known) are computed leak-free at each fight date.
- No fight-camp, injury, short-notice, or betting-line features.
- Debut fighters have no data, so their bouts are skipped with a warning
  rather than predicted.

## How It Works

1. **Scrape** — `just scrape` pulls only events it hasn't seen (tracked in
   `data/raw/events.csv`) and refreshes profiles of fighters who fought.
2. **Prepare** — features are engineered from prior fights only (expanding
   windows shifted by one), fighters are randomly assigned to A/B for a ~50/50
   target, and imputation parameters are fitted on the training split and saved
   with the model so prediction uses identical values.
3. **Train** — three candidates are compared on a temporal holdout (most recent
   18 months); the best is saved as a scikit-learn Pipeline with its metadata,
   and the previous bundle is archived.
4. **Predict** — pick a matchup in the app, or predict a whole upcoming card
   (scraped live). Saving a card records the predictions as pending.
5. **Review & retrain** — after the event, one click fetches results, matches
   them to pending predictions (by fighter-id pair, robust to card shuffles and
   duplicate names), shows hit rate + Brier score, and retrains on approval.

## Quickstart

```bash
uv sync            # install dependencies (installs the ufc package editable)
just app           # launch the Streamlit UI

# or headless:
just scrape                    # update data/raw incrementally
just train                     # rebuild features + retrain
just predict-card --save       # predict the next event and record it
just update-results            # after the event: fetch results + score
just test                      # run the test suite
```

## Trying it out

`just app` opens the Streamlit UI; a good walkthrough:

1. **Matchup** — pick two fighters (try "Bruno Silva" to see duplicate-name
   disambiguation) and a weight class; get a probability.
2. **Fight Card** — select the next event; note the debut-fighter warning rows;
   click *Save predictions*.
3. **Value Bets** — pick the next event and a sportsbook; the model's win
   probabilities are compared against that book's live odds (from fightodds.io)
   to flag fights where the price offers positive expected value.
4. **Model** — check the current model, metrics, and training date.
5. **Review & Retrain** — after the event happens, click *Fetch results*,
   review predicted vs actual, then *Approve & retrain*.

Every step has a headless equivalent: `just scrape`, `just train`,
`just predict-card --save`, `just update-results`, `just model-info`.

## Tech Stack

- **Python 3.14** with uv for dependency management
- **scikit-learn** for model training
- **pandas / numpy** for data processing
- **BeautifulSoup + requests** for scraping (handles ufcstats.com's
  proof-of-work anti-bot gate)
- **Streamlit** for the UI
- **pytest** for tests, **just** for task running

Note: `data/raw/*.csv` (~2 MB) is committed so the project works out of the
box and history is reproducible; it grows slowly as events are scraped.
